# Rust2Go Example for Monoio

Runtime: Monoio
Calling Direction: Rust -> Go
Backend Technology: CGO

Run with `cargo run -p example-monoio`.

This example shares its demo with the other Rust -> Go examples; only the
runtime-specific `src/main.rs`, `Cargo.toml` and `go/go.mod` live here. The
shared pieces are:

- `examples/shared/user_cgo.rs` — structs and the `DemoCall` trait, pulled in
  via `#[path = "../../shared/user_cgo.rs"] mod user;` in `src/main.rs`;
- `examples/shared/build_cgo.rs` — build script body, pulled into `build.rs`
  via `include!`;
- `go/impl.go` — a byte-identical copy of `examples/shared/impl.go.tmpl`
  (sync enforced by CI);
- `go/gen.go` — generated by `build.rs` on every build, not committed.

On top of the shared demo, `src/main.rs` also calls the zero-argument
(`demo_get_n`) and multi-argument (`demo_sum`) methods and contains an unused
`perf` helper for QPS testing.

See [examples/README.md](../README.md) for the step-by-step walkthrough.
