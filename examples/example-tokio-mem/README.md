# Rust2Go Example for Tokio with Shared Memory based Implementation

Runtime: Tokio
Calling Direction: Rust -> Go
Backend Technology: Shared Memory Lockless Queue

Run with `cargo run -p example-tokio-mem`.

This example shares its demo with the other Rust -> Go examples; only the
runtime-specific `src/main.rs`, `Cargo.toml` and `go/go.mod` live here. The
shared pieces are:

- `examples/shared/user_mem.rs` — structs and the `DemoCall` trait (with the
  `#[mem]` call attributes), pulled in via
  `#[path = "../../shared/user_mem.rs"] mod user;` in `src/main.rs`;
- `examples/shared/build_mem.rs` — build script body, pulled into `build.rs`
  via `include!`;
- `go/impl.go` — a byte-identical copy of `examples/shared/impl.go.tmpl`
  (sync enforced by CI);
- `go/gen.go` — generated by `build.rs` on every build, not committed.

Note: the demo sleeps 1s at the end because the shm-based call currently has
no elegant quit mechanism.

See [examples/README.md](../README.md) for the step-by-step walkthrough.
